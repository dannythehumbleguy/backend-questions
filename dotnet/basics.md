# Базовые понятия

## Асинхронность и многопоточность

**Процесс** - под ним подразумевают исполнение программы, нужны для изоляции программ.

**Поток(Thread)** - основная единица параллельного выполнения программы.

**Aсинхронное выполнение** - выполнение, при котором не происходит блокировка потока во время ожидания IO Bound операций.
