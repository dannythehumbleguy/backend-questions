# Fundamentals

## Databases

**Transaction** — a set of operations that forms a logical unit of work with data.

**Data consistency** — the absence of internal contradictions in data according to the system's rules.

## Data structures

**Hash function** — maps input data to a fixed-size result. Different hashes imply different inputs, but equal hashes do not imply equal inputs, so matching hashes require comparison of the original data.

## Networks

**Protocol** — rules that define how network nodes exchange data.
