# Базовые понятия

## Базы данных

**Транзакция** - набор операций, который является логической единицей работы с данными.

**Согласованность/Консистентность данных** - внутренняя непротиворечивость данных, исходя из логики системы.

## Структуры данных

**Хэш-функция** - функция, которая приобразовывает любой набор данный в данные определенной длинны. При этом если результаты такой функции различны, то и исходные данные разлины, обратное не верно, а значит при совпадении результатов нам нужно будет сравнить исходные данные полностью.

## Сети

**Протокол** - это набор правил, определяющий, как узлы сети должны передавать данные друг другу.
