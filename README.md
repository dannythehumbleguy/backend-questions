Для новых вопросов частота перенесена из числовых отметок Notion: 0–1 — редко, 2 — средне, 3 и более — часто. Если отметки нет, указано «не указана». Частоты уже перенесённых вопросов сохранены.

Подробные объяснения доступны по ссылкам в ответах; изображения хранятся локально. Незавершённые ответы отмечены `TODO`, как в исходной базе.

# Правила для контрибьторов
> 1. Вопрос должен быть из реального собеседования, соответствовать структуре, ответ на него должен быть краток.
> Если вы были на собеседовании и вам попался один из вопросов вы можете увеличить его счетчик.<br>
> 2. Желательно избегать общих/широких вопросов по типу "Что такое шардирование?".<br>
> 3. Вопросы учитываются только на позиции middle-senior.
